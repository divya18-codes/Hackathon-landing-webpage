05. GCPD PROTOCOL

Team Rules & Eligibility

Teams: 2–4 members. All must be current students. One participant per team. Register by Oct 20.

Code Originality

70% code written during hackathon. APIs, open-source libs, frameworks allowed—disclose all dependencies.

AI Usage Policy

AI tools allowed. Must understand and document all AI-assisted code. Verify functionality. Final product must reflect your creativity.

Code of Conduct

Zero tolerance: No harassment, discrimination, hate speech, plagiarism, or malicious activity. Violations → disqualification.

Submission Checklist:

  • ☐ Working Prototype / MVP
  • ☐ Public GitHub Repository & README
  • ☐ Presentation Deck (5–10 slides)

07. BATCOMPUTER DATABASE

Who can participate?

Current students from any college, any discipline. Teams of 2–4.

What's the team size?

Teams must be 2–4 members. Each member registers; no solo entries.

Can AI tools be used?

Yes. AI allowed for ideation, coding, debugging. Must understand and document all AI-assisted code.

Is there a fee?

No registration fee. Free participation for all eligible students.

Can I start building before?

No. All development begins at official start time. Pre-hackathon: learn, plan, setup environment only.

What to bring?

Bring: Laptop, charger, ID. Provided: WiFi, workspace, meals, mentors.
