 🦇 Gotham: Zero Hour — 24-Hour Hackathon Landing Page

> *"The city needs builders. One night. Twenty-four hours to build something real."*

A production-ready, highly interactive landing page for **Gotham: Zero Hour**, a 24-hour college hackathon built for the Web Recruitment Task (Task 2). The site features a dark GCPD terminal aesthetic, movie-accurate Bat-Signal lighting effects, interactive 3D tilt cards, and smooth terminal text decryption.


 **GitHub Repository:** [https://github.com/divya18-codes/Hackathon-landing-webpage.git]


## 🚀 Key Features

* **Thematic Design & Storytelling:** Custom GCPD terminal visual identity with dark UI, gold/amber accents, and movie-accurate Bat-Signal background projections[cite: 1].
* **Responsive Layout:** Fully optimized across desktop, tablet, and mobile devices with fluid CSS grid layouts
* **Interactive FX & Animations:**
  * Custom pure CSS movie-accurate Bat-Signal spotlight beam.
  * JavaScript terminal text scramble/decryption on section scroll
  * Modern CSS scroll-driven reveals 
  
* **Performance Focused:** Built with native, modular HTML5, CSS3, and JavaScript—delivering instant load speeds with zero frame drops or bundle bloat[cite: 1].

---

## 🛠️ Built With

* HTML5: Semantic architecture and accessibility considerations
* CSS3: Custom properties, CSS Grid/Flexbox, radial SVG masks, and keyframes
* JavaScript: Modular DOM manipulation, `IntersectionObserver`, and text scramble engines
